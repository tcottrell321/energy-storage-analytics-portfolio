# Residential Energy Optimization Portfolio

A growing collection of residential energy-system case studies. Each study tests load modeling, solar sizing, battery dispatch, EV charging, and flexible loads against a different household. Methods are promoted into shared tools only after they prove useful across cases.

## Structure

- `case-studies/` — public, anonymized case writeups when ready
- `shared/` — validated reusable methods and tools

The detailed Shah working case, measured utility data, customer documents, and proposal summaries live in a separate private repository. New customer cases begin privately, then may be summarized here with identifying details removed or permission obtained. Earlier public commits contained named Shah summaries; moving them off the current branch does not erase Git history.
